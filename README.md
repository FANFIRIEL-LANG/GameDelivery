# GameDelivery

Локальная программа для автоматизации заказов игровых предметов.

## Принципы проекта
- Playerok — источник заказов; вход выполняет пользователь в локальном окне приложения.
- Steam API не используем.
- Telegram используется только для уведомлений и статистики.
- Реальная отправка предметов выключена, пока адаптеры и тесты не проверены.
- Поддержка игр расширяется отдельными модулями: Steam-карточки, Counter-Strike 2 и будущие игры.

## Запуск Windows
Python 3.11+.

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app
```

Текущая версия — локальный UI-каркас. Она не подключается к Playerok и не отправляет предметы. Не вставляйте пароли, cookie или токены в issue, логи или исходники.
