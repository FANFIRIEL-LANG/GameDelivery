# GameDelivery — план доведения до готового результата

> **Для исполнителя:** выполнять задачи по порядку с тестами перед кодом; отмечать чекбоксы только после проверки. Не сливать изменения в `main`.

**Цель:** довести существующее приложение GameDelivery до проверяемого Windows-релиза для локального управления ASF, инвентарём, заказами и безопасной отправкой Steam-предложений.

**Архитектура:** оставить PySide6 UI, доменную логику в `games/steam_cards` и `core/orders`, интеграции в `integrations`, хранение в локальной SQLite и секреты в системном хранилище. Исправлять границы модулей только при доказанной проблеме.

**Стек:** Python 3.11+, PySide6, SQLite, keyring, GitHub Actions, .NET 10 для ASF-плагина.

**Спецификация:** `docs/superpowers/specs/2026-10-27-gamedelivery-ready-design.md`

## Глобальные ограничения

- Работать в `feature/asf-bulk-account-import`; `main` не менять и PR не сливать.
- Никаких настоящих секретов в исходниках, тестовых данных, логах, артефактах и issue.
- Steam-инвентарь и торговые операции — только через локальный ASF.
- Playerok — только чтение разрешённых продаж и импорт в локальную очередь.
- Отправка — вручную подтверждаемая; неизвестный результат не повторять автоматически.
- Сохранять текущую работающую логику и проверять изменения регрессионными тестами.
- Публичный репозиторий: перед релизом перепроверить историю, workflows, артефакты и игнорирование локальных конфигов/данных.

## Review Focus

- Некорректные или конфликтующие форматы строки прокси, особенно IPv6 и логин/пароль — ошибки должны быть понятными и не раскрывать пароль.
- ASF выключен, отсутствует, выбран неверный путь или IPC-пароль неверен — UI не зависает и показывает безопасную диагностику.
- Импорт TXT/maFiles содержит повреждённую, неполную или повторяющуюся запись — не выполнять частичное разрушительное изменение без отчёта.
- Инвентарь устарел или один asset ID появляется в нескольких ботах — не допускать двойной резервации/отправки.
- Отправка возвращает timeout/неизвестный результат — блокировать повтор и сохранять статус для ручной сверки.
